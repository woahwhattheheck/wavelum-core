# Changelog

All notable changes to Wavelum Core will be documented in this file.

This project follows the [Keep a Changelog] format. New entries belong under
[Unreleased] until a release is cut.

Contract changes must name the affected workspace member in the entry, using
the contract name as a bold prefix. The current Cargo workspace members are:

- `vesting_contracts`
- `grant_contracts`
- `staking_contract`
- `vesting_status_nft`
- `vesting_vault`
- `deposit_to_yield_adapter`
- `insurance_treasury`

Existing project history predates this changelog; Git history remains the
record for changes made before this baseline. Contract changes from this point
forward must be recorded here.
